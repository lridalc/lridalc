🎯 Objetivo: simular un entorno backend real (no proyecto académico)

### 🌦️ Weather Analytics Dashboard

🔗 https://github.com/lridalc/weather-analytics-dashboard

Proyecto personal diseñado para aprender desarrollo backend en un entorno real.

No está planteado como un proyecto básico, sino como una forma de trabajar con prácticas reales de desarrollo:

- Arquitectura y separación de responsabilidades (Clean Code y Clean Architecture)
- APIs y comunicación cliente-servidor
- Modelado de datos
- Asincronía
- Bases de datos (SQLite)
- Tooling profesional (Makefile, pre-commit hooks, Git workflow)
- Testing (TDD)
- Documentación (ADRs)
- CI/CD

👉 Este proyecto refleja cómo trabajo: priorizo aprender bien antes que hacer algo rápido.
